# Sudarshan Design Team
The mandatory design team is coordinated by Sudarshan.

1. Vishvakarma Liaison consults Rishi Vishvakarma and retrieves task-relevant verified knowledge.
2. UX Architect defines flows/states.
3. Visual Designer applies visual hierarchy and design language.
4. Design System Engineer maps tokens/components.
5. Responsive & Accessibility Engineer validates device and accessibility requirements.
6. Implementation Worker builds from the approved design specification.
7. Browser QA performs deterministic browser checks.
8. Visual QA performs render comparison/design-drift checks.
9. Sudarshan Verifier independently accepts or routes defects back for repair.

The Liaison is the bridge to Vishvakarma; every design/frontend project must pass through that consultation. Temporary workers may be retired after completion while findings/evidence return to Vishvakarma/Gyan-Bhandar. KRISHNA receives summary-only results.
