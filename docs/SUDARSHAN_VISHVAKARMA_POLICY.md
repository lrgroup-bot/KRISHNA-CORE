# Mandatory Sudarshan Vishvakarma Policy
For every UI, UX, frontend, dashboard, mobile-UI, component, visual-redesign or image-to-code task, Sudarshan MUST retrieve relevant Rishi Vishvakarma knowledge before implementation.

A design task cannot receive Sudarshan acceptance unless these gates pass: Vishvakarma knowledge retrieval, design specification, functional verification, visual verification, responsive verification, accessibility verification and security verification.

This requirement is scoped to design/frontend work so backend and unrelated jobs are not burdened. KRISHNA remains summary-only; Sudarshan owns enforcement.
