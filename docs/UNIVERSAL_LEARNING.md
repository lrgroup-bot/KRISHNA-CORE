# KRISHNA Universal Learning

KRISHNA must not depend on a fixed command phrase. Natural intent can request answering, investigating, remembering, studying or deeper research.

## Accepted evidence modalities

Mobile camera frames, video, audio/sound, speech, images, OCR/text, books/documents, webpages, diagrams, maps and authorized sensor observations can all become evidence sources. The runtime preserves the source reference and evidence state.

## Fast unknown-resolution path

1. Hawkeye attempts local recognition and existing-memory lookup.
2. A low-confidence or UNKNOWN result is written to the Unknown Registry.
3. KRISHNA routes the subject to an appropriate Rishi.
4. Existing Gyan-Bhandar knowledge is checked.
5. A temporary specialist Shishya may be created for focused research.
6. Independent sources are cross-checked.
7. KRISHNA returns a provisional result quickly and deepens it when necessary.
8. Verified reusable findings may be promoted to Gyan-Bhandar; unresolved facts remain UNKNOWN.

The target is seconds for a useful first result, not a false guarantee that every scientific investigation finishes in seconds.

## Sound intelligence

Audio is a first-class modality. Candidate classes include speech, music, birds, animals, insects, vehicles, engines, machines, tools, alarms, impacts, water, rain, thunder, wind, fire and general environmental sound. Classification is evidence, not proof of hidden cause. Machinery anomaly detection should compare against an established baseline and must not claim a specific mechanical fault from sound alone without adequate evidence.

## Video learning

Video learning is multimodal: sampled frames + temporal changes + audio/speech + captions/OCR + diagrams/objects + metadata. KRISHNA stores what a source claims separately from what independent verification supports.

## Provenance

Use MEASURED / OBSERVED / INFERRED / PREDICTED / UNKNOWN for field evidence. Source claims are not silently converted into verified facts.
