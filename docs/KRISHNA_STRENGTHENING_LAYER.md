# KRISHNA Strengthening Layer

This layer extends existing authorities; it does not create competing runtimes.

- CodeBrain: deterministic local structural index and blast-radius evidence.
- ProjectTruthGraph: requirement -> code -> test -> runtime evidence traceability.
- ContextCompiler: bounded task context built from deterministic project truth.
- LSPTruth: invokes installed language analyzers with shell disabled.
- DAPTruth: fail-closed debugger contract until a pinned per-language adapter is configured.
- MissionReplayLedger: durable hashed step receipts and verified resume points.
- EvolutionIntelligence: before/after structural change evidence and conservative test-gap hints.
- CompetenceFeedback: measurable agent/domain success rates for BRAHMA training decisions.
- OTelGenAIExporter: vendor-neutral span mapping without prompt export.
- KabachAgentEvaluation: isolated, authorization-required AI security evaluation plans.
