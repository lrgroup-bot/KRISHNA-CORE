# PRAHARI + Local Model Evolution

## PRAHARI
Always-on observation only. It watches expected processes for crash, failure, degradation, blockage, repeated failure and unexplained idle time. It reports to BRAHMA and routes operational faults to MRITYUNJAY. Structural improvements route to VISHWAKARMA. PRAHARI never edits production.

## VISHWAKARMA Local Model Evolution
Discover new local models from public/official sources; verify license/source and ₹0 status; compare declared RAM/VRAM/disk needs with the actual machine; download eligible models into quarantine; benchmark quality/stability/latency/task fit; never auto-promote merely because a model is newer. Promotion remains governed by KRISHNA/SUDARSHAN.
