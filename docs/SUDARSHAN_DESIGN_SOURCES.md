# Sudarshan Design Sources
External projects are adapters/reference sources, not automatically trusted runtime code.
- Taste Skill: design critique and image-to-code concepts.
- web-design: spec-first DESIGN.md workflow.
- Awesome Claude Design: inspiration library; do not clone protected brands/assets.
- Playwright CLI: deterministic browser QA.
- Stagehand: optional agentic/self-healing browser mode.
- Storybook: isolated component-state verification.
Sudarshan loads only the capability needed for the current job and returns summary-only results to KRISHNA.
